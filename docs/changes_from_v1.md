# Зміни відносно версії 1

Версія 1 — репозиторій `Multimodal-Transformer-KiTTi` (скрипти `Lidar_Cropper.py`,
`dataset_crooper.py`, `main.py`, `inference_script.py`). Версія 2 переносить той самий підхід
у модульну структуру зі звіту (розділ 6) та виправляє знайдені дефекти.

## Виправлені дефекти

## Нова функціональність

* Маскування відсутньої/темної камери та modality dropout (NFR-05), оцінка LiDAR-only.
* CLS-токен і modality embeddings замість mean pooling.
* Аугментація: обертання хмари навколо вертикальної осі, масштаб, шум; фотометрична аугментація зображень.
* AdamW + OneCycle, AMP, gradient clipping, early stopping.
* Експорт ONNX (перевірено на відповідність PyTorch) і побудова TensorRT engine (FP16).
* Бекенди інференсу `torch` / `onnxruntime` / `tensorrt` з однаковим інтерфейсом.
* ROS 2: ROI extraction (RANSAC + евклідова кластеризація + OBB), вузол інференсу з
  `/detected_objects`, маркери RViz2, програвач KITTI, launch-файл з FAST-LIO2.
* Журнал детекцій SQLite (модель даних зі звіту, розділ 5).
* 44 автоматичні тести, black + flake8 + pre-commit.
